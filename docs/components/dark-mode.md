# Dark Mode

`<ui-dark-mode>` manages light, dark, and system color themes with localStorage persistence.

## Basic usage

```html
<ui-dark-mode mode="auto" class="btn">Toggle theme</ui-dark-mode>
```

## Attributes

| Name | Type | Default | Description |
|---|---|---|---|
| `mode` | `'auto'` \| `'light'` \| `'dark'` | `'auto'` | Active theme mode |
